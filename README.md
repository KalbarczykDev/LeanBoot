# LeanBoot

LeanBoot is simple version of Spring Boot framework made to learn more about java and Spring Boot. Core idea of the
project was to implement everything in Vanilla java without going crazy that is why LeanBoot implements its own
collections and framework algorithms, but uses the JDK for JVM reflection, class loading, filesystem access, networking,
concurrency, and primitive I/O.

### Main Implementation goals:
- Dependency Injection/ Inversion of control engine using custom Annotations 
- Implement every collection/algorythm that is required by hand.
- Implement simple web server 


### Optional Goals
- Implement simple version of hibernate/spring data jpa for PostgreSQL 
- Token based auth
